End-to-end test automation project built with Cypress, focused on testing user profile functionality in a Dockerized local environment.
The project follows Page Object Model (POM) to ensure scalable and maintainable test structure.

# QA Automation Activities
Developed end-to-end test automation suite using Cypress for user profile functionality (settings page)
Set up and tested application in a Dockerized local environment simulating real-world QA conditions
Implemented Page Object Model (POM) to ensure scalable, maintainable, and reusable test structure
Used data-cy attributes for stable and reliable element selection in UI tests
Generated dynamic test data using Faker to simulate realistic user inputs
Created reusable helper functions to reduce duplication and improve test maintainability
Followed Git workflow including branching, feature development, and pull request process
